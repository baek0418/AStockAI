# 研究与回测数据契约

本项目的正式研究入口是：

```bash
.venv/bin/python -m astock_core.research.oos_portfolio_research
```

入口先审计 `data/research_execution/manifest.json`。输入不完整时退出码为 2，写入带时间戳的拒绝记录，不训练模型、不计算收益。旧版“当前股票池 + 全区间共同日期 + 当日收盘成交”评分回测已经停用；已有历史结果只保留作问题基线。

## 输入目录

`manifest.json` 的版本为 1，并声明固定的逐日股票池规模及公司行为完整性。四个 CSV 都必须位于同一隔离目录，逐项记录相对路径、来源和 SHA-256：

```json
{
  "version": 1,
  "universe_size": 300,
  "corporate_actions_complete": true,
  "files": {
    "calendar": {"path": "calendar.csv", "source": "来源及提取批次", "sha256": "..."},
    "membership": {"path": "membership.csv", "source": "来源及提取批次", "sha256": "..."},
    "prices": {"path": "prices.csv", "source": "来源及提取批次", "sha256": "..."},
    "corporate_actions": {"path": "corporate_actions.csv", "source": "来源及提取批次", "sha256": "..."}
  }
}
```

文件字段如下：

| 文件 | 必需字段 | 审计规则 |
|---|---|---|
| `calendar.csv` | `日期` | 升序、唯一，定义信号及执行日 |
| `membership.csv` | `日期,股票代码,可得时间` | 每个交易日恰好为声明规模；记录须在信号截止前可得 |
| `prices.csv` | `日期,股票代码,收盘,成交量,复权方式,可买入,可卖出,可得时间,状态来源` | 交易价格必须为 `raw`；买卖状态必须显式给出；历史成分当日缺记录则拒绝整个实验 |
| `corporate_actions.csv` | `事件编号,股票代码,登记日,除权日,派息日,新增股份上市日,每股税后红利,每股送转股数,公告时间,类型` | 无事件也要提供表头；当前只接受已核验的 `distribution`。纯现金事件可空上市日，纯送转事件可空派息日 |

股票统一使用六位代码作为稳定标识，不能用当前名称追溯历史。校验值可以证明回放使用的是哪批文件，但不能独立证明数据供应方没有事后修订；来源、提取批次和可得时间仍需保存。

## 回放规则

- 历史股票池按每个信号日合并，退市或调出股票不会被今天的成分名单删除，晚上市股票也不会要求覆盖实验起点。
- 特征只使用当时已经发生的公司行为构造因果收益序列。模型标签按全市场交易日计算，不把个股缺失的五根记录误当成五个交易日。
- `t` 日收盘后生成信号，最早在下一交易日以原始收盘价、滑点及费用模型执行。信号排名不会根据下一日能否买入而替换为排名更低的股票。
- 停牌、涨跌停等状态不从 OHLCV 推断。缺少明确买入或卖出许可时拒绝委托；持仓估值价格缺失时终止回放，不前填、不删股。
- 登记日按收盘持仓登记权益；除权日确认红利应收及送转股份；现金到派息日才可用；新增股份到上市日才可卖。应收红利计入净值，但不能提前用于交易。
- 基准必须覆盖每个组合估值日。报告保存输入、基准和关键代码校验值、依赖版本、滚动窗口、信号与成交记录。

## 当前边界

2026-09-09 的 BaoStock 探针证明可取得历史沪深 300 成分、分红字段和 `tradestatus`，两次历史成分样本各 300 只且有 61 只发生替换，说明用当前成分回填历史会产生明显偏差。但该探针仍不能直接形成严格输入包：历史成分的 `updateDate` 不是精确公告可得时间；`tradestatus` 不能证明涨跌停方向上的可买卖性；税后红利字段存在多情景文本。探针原始响应保存在 `output/research_input_probe/20260909_154020/`，未调用东方财富接口。

因此，当前代码已经具备严格回放和拒绝机制，真实策略收益仍须等上述证据补齐后再计算。收盘价加固定滑点只是一项可复核成交假设，也不证明真实成交量；股息税按输入的税后金额情景处理，不模拟持有期税款追缴。配股、合并、退市结算等事件尚未支持，出现时会拒绝运行。

候选数据先放在正式目录之外，并提供 `evidence.json`、`calendar.csv`、`membership.csv`、`prices_raw.csv`、`execution_states.csv` 和 `corporate_actions.csv`。运行 `.venv/bin/python -m scripts.build_research_package --candidate-directory <候选目录>` 后，构建器会逐行验证不复权标志、合并独立交易状态，并调用正式加载器二次校验；全部通过才原子发布到 `data/research_execution/`，且绝不覆盖已有正式包。探针准备度可运行 `.venv/bin/python -m scripts.build_research_package --audit-probe <探针目录>`。
