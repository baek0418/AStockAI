# AStockAI 开源量化能力接入方案

## 已下载的上游基线

- Qlib：`external/qlib`，提交 `79633dd`，MIT。
- easy-tdx：`external/easy_tdx`，提交 `e533b70`，MIT。

两个目录都是独立 Git 仓库，当前 AStockAI 不依赖它们，现有日报、Web 页面、预测模型和定时任务保持不变。

## 目标架构

```text
easy-tdx / 现有日线源
        ↓
统一的 A 股数据适配层（本项目新增）
        ↓
Qlib 数据集 + 因子库 + 模型实验
        ↓
滚动样本外评估 + 成本约束组合回测
        ↓
仅将经验证的研究快照输出到现有 Streamlit / 日报
```

## 分阶段实施

### 1. 数据适配层

新增独立模块，将现有 CSV 与 easy-tdx 日线输出转换为统一、可审计的长表。每条数据必须保留：股票代码、交易日期、复权方式、来源、下载时间和最新数据日期。此阶段不替换现有数据更新流程。

现阶段已实现本地 CSV 适配器，可运行 `.venv/bin/python market_data_adapter.py`。它只读取 `data/*.csv`，将结果和审计写入 `output/research/`；复权方式无法由既有 CSV 验证时会明确写为 `unknown`，不会擅自标记为前复权或后复权。easy-tdx 的实时/历史数据适配将在其数据一致性验证后接入。

验收标准：同一只股票的适配后 OHLCV 与源文件可逐行核对；异常、停牌和缺失交易日可被报告；不会把未来数据混入训练集。

### 2. Qlib 研究基线

在独立环境安装 Qlib，将研究股票池转换为 Qlib 的 CN 数据格式；以当前“未来 5 日跑赢沪深 300”的目标建立 LightGBM/Alpha158 基线，并使用按日期整体切分、扩张窗口和 5 日 gap。

验收标准：输出每次实验的参数、训练/验证区间、样本数、IC/Rank IC、分类或超额收益指标、换手、成本后收益、最大回撤；没有完整样本外结果不得进入产品页面。

当前已完成本地 Qlib 二进制导出和最小研究基线：`market_data_provenance.py` 先核验复权来源，`qlib_local_export.py` 只导出已核验前复权数据，`run_qlib_alpha_baseline.py` 再运行样本外研究。完整 Alpha158 依赖成交额/VWAP；在既有 CSV 尚无成交额时，仅使用其 OHLCV 可严格计算的子集，并在报告中标记为 `Alpha158-reduced`。本机 LightGBM 缺少 `libomp.dylib`，故基线临时使用 HistGradientBoosting，不能称为 LightGBM 结果。

### 3. 组合和交易约束

实现 A 股特有约束：T+1、100 股整手、涨跌停不可成交、停牌、佣金最低收费、印花税和滑点。Qlib 的模型信号只负责排序；真实成本和可交易性由本项目的回测适配层统一裁定。

验收标准：任一买卖记录均可追溯到信号日期、下单日期、成交价格和成本；回测不能使用收盘后才知道的数据在同一收盘成交。

### 4. 产品接入

将通过门槛的实验产物写入新的只读 `output/research/` 快照，并在 Streamlit 中清晰标注训练截止日、数据截止日、样本外表现与风险提示。日报只引用已验收的快照。

验收标准：模型不可用、数据过期或验证不达标时，页面不输出买卖结论；原有功能不受影响。

## easy-tdx 的边界

优先使用其行情、板块、资金流和公告能力，不直接采用其内置回测结果作为策略证据。通达信行情接口及免费网页类数据可能出现限流、字段变化或中断，因此所有新数据源都必须具备日期校验、来源标识和失败降级。

已验证 `easy-tdx 1.20.6` 的发布 wheel 可以在 Python 3.12 隔离环境中安装并通过 `easy-tdx --help` 自检。源码副本当前不能直接以 editable 模式安装：其打包配置强制包含未提交的 `web-ui/dist`，必须先构建前端产物。这是上游开发环境的接入风险，不应通过修改或提交该副本来规避；后续如需从源码安装，应在独立构建环境执行前端构建并记录产物版本。

## 依赖隔离

- 当前 `.venv`：继续运行 AStockAI，暂不安装 Qlib。
- Qlib：使用单独虚拟环境，因其包含 LightGBM、MLflow、CVXPY、PyArrow 等较重依赖。
- easy-tdx：接入前先在单独环境进行实时和历史数据一致性测试，再决定是否作为项目依赖。

## 不做的事

- 不把第三方代码直接复制进核心目录。
- 不基于未审计的回测收益生成推荐或自动下单。
- 不在没有券商模拟环境和独立风控检查前接入实盘交易。
