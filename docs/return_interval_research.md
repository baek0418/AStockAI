# 未来 5 日收益区间实验

这是一个独立的研究实验，不接入持仓、日报、Web 结论或自动交易。它试图回答的不是“目标价是多少”，而是：仅使用信号日可得 OHLCV 信息时，未来约 5 个交易日收益率的 80% 区间能否在样本外保持校准。

## 假设与范围

- 假设：OHLCV 技术特征可以构造比无条件收益率、历史波动率更有校准性的 5 日收益区间。
- 目标：`t` 日收盘至第 5 个后续交易日收盘的收益率。
- 股票范围：当前 `data/*.csv` 中可构造完整特征的正式股票；按报告明确记录，绝不读取 `on_demand` 缓存。
- 参考：现有 v5.1 是“是否跑赢基准”的分类实验，不能作为收益幅度预测的证据，因此不复用其通过/失败结果。

## 防泄漏设计

特征只使用信号日及以前的 OHLCV。按全市场交易日期做扩张式滚动切分，训练与测试之间留 5 个交易日间隔；训练窗口内再将尾部留为校准集，并在模型训练与校准之间另留 5 个交易日间隔。每个测试窗口都独立拟合模型和残差半径。

## 比较与验收

实验保留 HistGradientBoosting 回归的**波动率自适应残差校准区间**，并新增一个独立候选：**CQR（分位数回归 + 独立时间校准）**。CQR 直接学习未来收益的 10% 与 90% 边界，再用校准集决定最小外扩量；它能让上涨和下跌两侧的范围不同。报告同时保留全局残差、校准期收益率无条件分位数和历史波动率正态近似三个基线，并逐窗口记录覆盖率、平均宽度和中心预测 MAE。

只有同时满足以下条件才可能进入进一步人工审阅：至少 3 个成功窗口；整体覆盖率接近 80%；不明显逊于历史波动率基线；区间不明显更宽；并且价格历史通过严格时点可得性审计。CQR 只有在整体覆盖率更接近 80%、整体区间更窄且每个窗口均在预设覆盖率范围内，才可能替代简单的历史波动率范围。

对用户展示时不以“模型复杂”作为选择理由：若 CQR 没有在预设比较中胜出，默认展示“历史波动率风险范围”。它表达的是过去相似波动下未来 5 日常见的涨跌范围，不是目标价或买卖建议。

单股票查询页只在本地原始日线与已验证报告同时存在时展示该范围，并明确标出本地收盘日期、历史覆盖率和“不是目标价”的边界；它不会写入日报或持仓台账。

当前项目的日线默认是动态前复权数据。若没有历史时点复权因子或原始可执行价格依据，实验会保留计算结果但自动判定为拒绝接入，不能展示为预测区间。为此，项目提供独立的原始价格快照命令：它优先使用实测可返回未复权 `day` 序列的腾讯普通 K 线接口；公开的 [BaoStock](https://www.baostock.com/)（`adjustflag=3`）与东方财富仅作为备用。全部写入隔离目录，不影响正式前复权数据。快照保存来源、访问时间和价格口径，但仍会在实验报告中明确说明：公开来源的历史数据可能被服务商事后修订，不能把一次快照误称为交易所级别的完整时点数据库。

腾讯快照默认请求最近 1,200 个交易日，以增加不同市场状态的研究覆盖；若单只股票下载失败，既有快照会保留，不会写入半份数据。

## 运行

```bash
.venv/bin/python raw_interval_data.py
.venv/bin/python return_interval_research.py --data-directory data/raw_interval --data-label raw
```

原始快照应先完整保存并检查来源记录，再运行区间实验。两条命令都不会发送邮件、改写日报或创建任何交易指令。

报告写入本地 `output/research/return_interval_5d_<日期>.json`。它不会下载行情、发送邮件、改写日报或创建任何交易指令。
