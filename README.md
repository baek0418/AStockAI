# AStockAI

面向 A 股的本地量化研究与信息整理工具。它提供股票池扫描、日报生成、历史数据研究、概率模型实验，以及一个仅绑定本机的 Streamlit 查询界面。

> 本项目仅用于技术研究与教育，不构成投资建议，也不保证任何模型、信号或历史回测的有效性。

## 快速开始

需要 Python 3.10+。

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

在 `.env` 中按需填入 AI 服务和邮件 SMTP 配置；未配置时，相关功能会明确提示并保持不可用。请勿提交 `.env`。

启动本地查询界面：

```bash
.venv/bin/streamlit run app.py
```

页面通过 `.streamlit/config.toml` 仅绑定 `127.0.0.1`，不部署公网。它读取本地生成的快照、日报和关注列表，用于展示首页概览、单股票查询与只读关注列表。

- 单股票查询支持代码、全名和模糊名称；多个候选项可在页面选择。
- AI 分析只有在点击“生成/刷新 AI 分析”后才会调用既有分析接口；AI 不可用时仍显示规则分析。
- 缓存以数据文件修改时间为键，新的快照、日报或关注列表写入后会自动刷新。
- 页面不会下载行情、运行回测、修改指标或股票配置、发送邮件，也不会显示 API Key、SMTP 授权码或环境变量。

## 任意 A 股按需查询（v4.5）

“单股票查询”会先复用已有 `quant_snapshot` 中的股票，避免重复下载。对于其他 A 股：

1. 输入六位代码，或先点击“更新本地代码目录（可选）”后按名称、模糊名称查找；目录只保存代码与名称。
2. 选择候选股票后，点击“下载并分析”才会请求这一只股票的历史日线。
3. 临时日线与分析快照分别保存在 `data/on_demand/`、`output/on_demand/`，不参与日报、研究股票池或回测。
4. 页面会标注最近日线数据日期；它不是实时盘中行情。AI 分析仍须手动点击触发。
5. “加入关注列表”是唯一会修改 `watchlist.json` 的显式操作，新增股票将在下一次股票池更新时生效。

六位代码直查不依赖名称目录：点击下载后会由腾讯接口识别股票并获取日线。名称和模糊名称仅使用已有本地目录；目录刷新失败（包括代理错误）时，页面会提示可继续输入六位股票代码。按需快照会记录行情来源与名称目录来源；不会修改用户代理配置或尝试绕过代理。

## 未来 5 日上涨概率研究基线（v5.0）

该研究管线只读取 `data/` 根目录的本地历史 CSV，不下载行情，也不会改动评分、日报、邮件或回测。

```bash
.venv/bin/python train_prediction.py
.venv/bin/python predict_probability.py 300750
```

训练会使用扩张窗口、按日期整体切分和 5 个交易日 gap 的样本外验证，并写入 `models/` 与 `output/prediction/`。概率输出必须以样本量、样本外表现、校准分桶、永远预测上涨率基线及风险提示为前提；未通过最低验证要求时会拒绝展示概率。结果仅作量化研究，不构成投资建议。

## 基准感知跑赢市场研究（v5.1）

v5.1 与 v5.0 完全隔离：它仅读取 `data/*.csv` 的正式股票日线，以及由用户显式下载到 `data/market/` 的市场指数日线。指数不会混入股票训练目录，也不会自动下载、接入日报、邮件或 Web。

```bash
.venv/bin/python prediction_data_audit.py
.venv/bin/python prediction_benchmark_data.py
.venv/bin/python train_prediction_v2.py
.venv/bin/python prediction_comparison.py
.venv/bin/python predict_outperformance.py 300750
```

基准下载命令会通过既有腾讯日线接口依次验证并保存 `sh000300`（沪深300）和 `sh000852`（中证1000）；失败时不会伪造 CSV。当前 v5.1 训练默认以沪深300为基准，预测目标是“未来 5 个交易日跑赢市场基准的实验概率”，不是涨跌或买卖建议。只有完整样本外验证报告存在时才会输出概率；即使通过最低技术检查，仍保持研究隔离，须以对比报告人工审阅后再决定是否展示。

## 隐私与开源发布

仓库不会包含 API 密钥、SMTP 密码、邮箱地址、个人关注列表、本地行情数据、模型文件、日志、日报或打包产物。它们均由 `.gitignore` 排除。提交前仍建议运行一次凭据扫描，并确认 `.env` 没有被暂存。

## 组合级研究回测

`portfolio_backtest.py` 将**已经在交易日可得的样本外信号**转换为组合回测结果；它不会训练模型或读取未来信号。输入 CSV 必须包含 `日期`、`股票`、`收盘`、`信号`，可选 `可买入`、`可卖出` 用于显式模拟停牌或涨跌停限制。

```bash
.venv/bin/python portfolio_backtest.py signals.csv \
  --benchmark data/market/沪深300_sh000300.csv \
  --max-positions 5 --rebalance-interval 5
```

默认配置包含等权仓位上限、5 日调仓、交易佣金、最低佣金、卖出印花税、滑点和 100 股整手约束。报告会写入 `output/portfolio/`，并包含净值曲线、交易明细和参数；这些研究产物不会被提交。组合回测结果仍只用于研究，不构成投资建议。
